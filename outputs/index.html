电价预测项目总览

项目: 平湾电力市场 XGBoost 实时电价预测

数据范围: 仅 2025 年 (2026 数据忽略)

切分: 训练 2025-01~10 / 验证 11 / 测试 12 (方案 B)

终版测试集: MAE = 32.38 元/MWh (vs B7' 日前价 34.85, RMSE 改进 +10.35%)

报告导航

  • ① 数据清洗报告 — 清洗策略 / 缺失率 / 异常过滤
  • ② 数据划分报告 — 4 切分方案对比 + 选定方案 B 的理由
  • ③ 相关性分析报告 — 与目标 Pearson + 数据泄漏识别 + 业务解读
  • ④ 模型训练报告 — 残差预测设计 + 抗过拟合超参 + 训练曲线 + 特征重要性
  • ⑤ 模型评测报告 — 时序/散点/误差/分段诊断 + Naive baseline 对比
